Informativa sulla privacy — AthleteOSlite

Ultimo aggiornamento: 29 settembre 2026

  • Chi la usa. AthleteOSlite è un'applicazione personale, usata esclusivamente dal suo autore. Non è offerta ad altri utenti.
  • Accesso a Google Drive. L'app richiede solo l'autorizzazione drive.file: può vedere e modificare esclusivamente i file che crea essa stessa, nella cartella AthleteOSlite del Google Drive dell'autore. Non legge né modifica altri file.
  • Dati trattati. File di testo con i dati di allenamento dell'autore, generati dal suo server personale.
  • Condivisione. Nessun dato viene venduto, condiviso o trasmesso a terzi.
  • Conservazione e cancellazione. I dati restano sul server personale dell'autore e nel suo Google Drive. L'accesso si revoca in qualsiasi momento da myaccount.google.com/permissions.
  • Contatti. github.com/fra9tos

English summary: AthleteOSlite is a personal app used only by its author. It requests only the drive.file scope, so it can access only the files it creates in the author's own Google Drive folder "AthleteOSlite". No data is sold or shared with third parties. Access can be revoked at myaccount.google.com/permissions.
